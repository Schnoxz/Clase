MySQL gestiona el acceso mediante usuarios identificados por nombre + host. El host 'localhost' restringe la conexión a la propia máquina; '%' permite conexiones desde cualquier lugar.
-------------------------------------------------------------------------

-- Crear usuario
CREATE USER 'alumno'@'localhost' IDENTIFIED BY 'miPassword123';

-- Crear usuario accesible desde cualquier IP
CREATE USER 'alumno'@'%' IDENTIFIED BY 'miPassword123';

-- Eliminar usuario
DROP USER 'alumno'@'localhost';

Gestión de privilegios
-------------------------------------------------------------------------
El comando GRANT asigna permisos y REVOKE los retira. Siempre se deben asignar solo los privilegios necesarios (principio de mínimo privilegio).

-- Todos los privilegios sobre una base de datos
GRANT ALL PRIVILEGES ON empresa.* TO 'alumno'@'localhost';

-- Solo SELECT e INSERT sobre una tabla concreta
GRANT SELECT, INSERT ON empresa.clientes TO 'alumno'@'localhost';

-- Revocar permiso INSERT
REVOKE INSERT ON empresa.clientes FROM 'alumno'@'localhost';

-- Ver privilegios de un usuario
SHOW GRANTS FOR 'alumno'@'localhost';

Crear usuario con acceso limitado
-------------------------------------------------------------------------
Crea un usuario llamado vendedor con contraseña vend2024 que solo pueda conectarse desde localhost. Asígnale permisos de SELECT, INSERT y UPDATE sobre la tabla tienda.pedidos.

CREATE USER 'vendedor'@'localhost' IDENTIFIED BY 'vend2026';

GRANT SELECT, INSERT, UPDATE ON tienda.pedidos
TO 'vendedor'@'localhost';
-------------------------------------------------------------------------
Revocar y eliminar
Al usuario vendedor ya no se le permite modificar pedidos. Revoca el permiso UPDATE y, posteriormente, elimina el usuario por completo.

REVOKE UPDATE ON tienda.pedidos FROM 'vendedor'@'localhost';

DROP USER 'vendedor'@'localhost';
