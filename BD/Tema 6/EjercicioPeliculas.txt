-- Encuentra todas las películas que se hayan estrenado después (o igual) del año 2010

Se usa $gte greaterThanOrEquals

db.peliculas.find({
  año: { $gte: 2010 }
})

-- Encuentra todas las películas que pertenezcan al género "Drama"
Se busca el array de genero

db.peliculas.find({
  genero: "Drama"   // MongoDB busca dentro del array automáticamente
})

Tambien puedo usar un filtro para que solo devuelva el titulo y no todos los valores

db.peliculas.find(
  { genero: "Drama" },   
  { titulo: 1 }  
)


-- Encuentra las películas que NO hayan ganado un Oscar

db.peliculas.find({
  oscar: false
})
