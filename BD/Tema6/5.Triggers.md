Un trigger es un programa que se ejecuta automáticamente cuando ocurre un evento DML (INSERT, UPDATE o DELETE) sobre una tabla. Se activa para cada fila afectada.
-------------------------------------------------------------------------

CREATE TRIGGER nombreTrigger
{BEFORE | AFTER} {INSERT | UPDATE | DELETE}
ON nombreTabla FOR EACH ROW
instrucciones;


Evento	OLD disponible	NEW disponible
INSERT	    No	            Sí
UPDATE	    Sí	            Sí
DELETE	    Sí	            No


Ejemplo: auditoría de cambios
-------------------------------------------------------------------------
Antes de actualizar un empleado, se guarda el estado anterior en una tabla de historial.

CREATE TRIGGER antes_update_empleado
BEFORE UPDATE ON Empleados
FOR EACH ROW
BEGIN
    INSERT INTO historial_empleados
        (idEmpleado, apellidoAnterior, fechaCambio)
    VALUES
        (OLD.idEmpleado, OLD.apellido, NOW());
END;

OLD.campo accede al valor previo al cambio. NEW.campo accede al valor nuevo que se va a guardar.


Recursividad
Un trigger que modifica su propia tabla puede causar un bucle infinito

Rendimiento
Código complejo en triggers ralentiza inserciones y actualizaciones masivas

Mantenimiento
Son difíciles de depurar; documenta bien cada trigger que crees

Coordinación
Evita duplicar lógica entre triggers y la capa de aplicación


Trigger de control de stock
-------------------------------------------------------------------------

Crea un trigger after_insert_venta que, tras insertar una fila en la tabla ventas(idProducto, cantidad), actualice automáticamente el campo stock en la tabla productos restando la cantidad vendida.

CREATE TRIGGER after_insert_venta
AFTER INSERT ON ventas
FOR EACH ROW
BEGIN
    UPDATE productos
    SET stock = stock - NEW.cantidad
    WHERE id = NEW.idProducto;
END;



Trigger de auditoría en DELETE
-------------------------------------------------------------------------
Crea un trigger before_delete_cliente que, antes de eliminar un cliente, guarde su id, nombre y la fecha actual en una tabla clientes_eliminados(id, nombre, fechaEliminacion).


CREATE TRIGGER before_delete_cliente
BEFORE DELETE ON clientes
FOR EACH ROW
BEGIN
    INSERT INTO clientes_eliminados
        (id, nombre, fechaEliminacion)
    VALUES
        (OLD.id, OLD.nombre, NOW());
END;


Trigger con validación
-------------------------------------------------------------------------
Crea un trigger before_insert_empleado que impida insertar un empleado con salario negativo lanzando un error con SIGNAL SQLSTATE '45000'.

CREATE TRIGGER before_insert_empleado
BEFORE INSERT ON Empleados
FOR EACH ROW
BEGIN
    IF NEW.salario < 0 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT =
            'Error: el salario no puede ser negativo';
    END IF;
END;
