Una transacción es un conjunto de sentencias SQL que se ejecutan como una unidad atómica: o todas tienen éxito (COMMIT) o todas se deshacen (ROLLBACK).
-------------------------------------------------------------------------

START TRANSACTION
Inicia una nueva transacción

COMMIT
Confirma los cambios de forma permanente

ROLLBACK
Cancela todos los cambios de la transacción

SET autocommit
Activa/desactiva confirmación automática

Las sentencias DDL (CREATE, DROP, ALTER) no pueden revertirse y cierran la transacción actual implícitamente.

Ejemplo: transferencia bancaria
-------------------------------------------------------------------------
El caso clásico para entender las transacciones: si una operación falla a mitad, el ROLLBACK evita que el dinero "desaparezca".

START TRANSACTION;

-- Descontar de la cuenta origen
UPDATE Cuentas SET balance = balance - 500
WHERE numeroCuenta = 'ES001';

-- Abonar en la cuenta destino
UPDATE Cuentas SET balance = balance + 500
WHERE numeroCuenta = 'ES002';

-- Si todo fue bien, confirmar
COMMIT;

-- Si algo falló, deshacer (en el bloque de manejo de errores)
-- ROLLBACK;

MySQL tiene autocommit activado por defecto: cada sentencia fuera de una transacción explícita es atómica por sí sola. Para agrupar operaciones usa siempre START TRANSACTION.

Compra de producto con stock
-------------------------------------------------------------------------
Escribe una transacción que registre la venta de 3 unidades del producto con id=10: debe insertar una fila en ventas y decrementar el stock en la tabla productos. Confírmala al final.


START TRANSACTION;

INSERT INTO ventas (idProducto, cantidad, fecha)
VALUES (10, 3, NOW());

UPDATE productos
SET stock = stock - 3
WHERE id = 10;

COMMIT;


Deshabilitar autocommit
-------------------------------------------------------------------------
Desactiva el autocommit, elimina todos los registros de la tabla logs_temporales, verifica el resultado con un SELECT, y finalmente decide no confirmar los cambios.


SET autocommit = 0;

DELETE FROM logs_temporales;

SELECT COUNT(*) FROM logs_temporales; -- debería devolver 0

ROLLBACK; -- deshacemos, la tabla queda intacta

SET autocommit = 1; -- restaurar modo normal
