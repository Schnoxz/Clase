# Temario: Experiencia de Usuario (UX) vs Interfaz de Usuario (UI)

## 1. Definición de UX (User Experience)
El diseño de **Experiencia de Usuario (UX)** no se limita a lo visual. Es un proceso integral cuyo objetivo es crear productos, sistemas o servicios que proporcionen experiencias **significativas y relevantes** a los usuarios.

* **Alcance:** Abarca todo el proceso de adquisición e integración del producto.
* **Componentes:** Incluye branding (marca), diseño, usabilidad y funcionalidad.
* **Objetivo final:** Lograr un producto funcional que ofrezca una experiencia positiva, eficiente y satisfactoria. No basta con que sea "bonito"; tiene que resolver un problema del usuario de forma fluida.

## 2. Definición de UI (User Interface)
El diseño de **Interfaz de Usuario (UI)** se centra estrictamente en los aspectos **visuales e interactivos** de la interfaz.

* **Responsabilidad:** Determinar la apariencia (look) y el comportamiento interactivo (feel) del producto.
* **Elementos:** Layout (maquetación), paleta de colores, tipografía, botones y animaciones.
* **Objetivo final:** Asegurar que la interfaz sea visualmente atractiva, intuitiva y cohesiva.

## 3. Diferencias Clave: UX vs. UI
Para un desarrollador web (DAW), es vital entender que aunque trabajan juntos, atacan problemas distintos:

| Característica | UX (Experiencia de Usuario) | UI (Interfaz de Usuario) |
| :--- | :--- | :--- |
| **Enfoque** | La sensación general y la eficiencia al usar el sitio. | La apariencia y el estilo visual del sitio. |
| **Conceptos** | Facilidad de uso, comprensión, navegación, memorización. | Diseño gráfico, colores, fuentes, jerarquía visual. |
| **Momento** | Define la estructura y el prototipo (esqueleto). | Se aplica una vez aprobada la estructura (piel). |
| **Impacto** | Psicológico y funcional (¿funciona bien?). | Estético y emocional (¿se ve bien?). |

> **Nota para el examen:** Recuerda que una UI excelente no puede salvar una UX deficiente. Si el usuario no encuentra lo que busca (UX), no importa lo bonito que sea el botón (UI).
